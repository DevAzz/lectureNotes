# Конспекты лекций

Приложение для Windows 11 x64. Для сборки нужны JDK 25 и Maven. Пакет включает Java runtime, JavaFX 21, помощник WASAPI, Whisper и sherpa-onnx с моделями разметки спикеров. Для подключения к встрече нужен установленный Google Chrome.

## Сборка и запуск

```powershell
.\tools\build.ps1 -AppImage
```

Скрипт выводит путь к `LectureNotes.exe` в `target/dist`. Запускайте его из папки пакета в обычном сеансе Windows. JAR для разработки доступен в `target/standalone-app`; рядом лежит `audio-capture.exe`.

```powershell
java --module-path target/standalone-app/lib --add-modules 'javafx.controls,javafx.media' '--enable-native-access=javafx.graphics,javafx.media,org.xerial.sqlitejdbc,ALL-UNNAMED' -jar target/standalone-app/lecture-notes.jar
```

Помощник собирается штатным компилятором .NET Framework из Windows. Maven может отдельно собрать Java-часть командой `mvn package`.

При первой сборке скрипт загружает CPU- и CUDA-сборки whisper.cpp v1.8.4 и мультиязычную модель `ggml-large-v3-turbo-q5_0.bin`. Файлы проверяются по SHA‑256 и остаются в `target/whisper-cache`. CUDA-архив и модель можно положить туда вручную. Имя CUDA-архива — `whisper-cublas-12.4.0-bin-x64.zip`. Лицензии и ссылка на условия NVIDIA лежат рядом с движком. [Сборки whisper.cpp](https://github.com/ggml-org/whisper.cpp/releases/tag/v1.8.4) · [Модель Whisper](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-large-v3-turbo-q5_0.bin)

Для пакета с полной Large v3 FP16 положите `ggml-large-v3.bin` в `target/whisper-cache` и запустите `.\tools\build.ps1 -AppImage -FullWhisper`. Сборщик проверяет SHA‑256 модели. [Модель Large v3 FP16](https://huggingface.co/ggerganov/whisper.cpp/blob/fb5ed9369c26eaf08392504d8446da431e0fffb9/ggml-large-v3.bin)

При первой сборке скрипт также загружает sherpa-onnx v2.0.3 и веса pyannote Segmentation 3.0 и 3D-Speaker ERes2Net. Архивы остаются в `target/diarization-cache`, а движок, веса и лицензии входят в папку `app/diarization` пакета. [Диаризация sherpa-onnx](https://k2-fsa.github.io/sherpa/onnx/speaker-diarization/index.html)

## Запись и конспект

1. Введите предмет, название и HTTPS-ссылку SaluteJazz. Тему и фокус конспекта можно указать отдельно. «Сохранить карточку» сохраняет приглашение для повторного открытия через «Открыть для встречи». При сохранении пустого поля прежняя ссылка удаляется. Кнопка «Подключиться и записать» сохраняет карточку, открывает отдельное окно Chrome через Playwright и подтверждает запуск записи после допуска. Профиль встречи блокирует доступ сайтов к камере и микрофону.
2. Войдите в браузере и дождитесь допуска. Приложение начнёт захват, когда распознает активную комнату на HTTPS-origin приглашения или после перехода со старого адреса jazz.sber.ru на salutejazz.ru. Если экран комнаты остался нераспознанным, после допуска нажмите «Я на встрече · начать запись». Во время захвата на вкладке «Лекция» появляется предварительная расшифровка. Она обновляется по мере распознавания восьмисекундных фрагментов и использует движок, сохранённый во вкладке «Настройки» до начала записи. Чтобы продолжить слушать после остановки захвата, используйте «Остановить запись».
3. Откройте запись в библиотеке и нажмите «Распознать» на вкладке «Расшифровка». Приложение запускает встроенный Whisper на NVIDIA GPU. Если CUDA не запускается, обработка продолжается на CPU. Движок, файл модели, язык распознавания и режим «Только CPU» задаются во вкладке «Настройки»; кнопка «Встроенные файлы» возвращает поставку. Пути также можно задать через `LECTURENOTES_WHISPER` и `LECTURENOTES_WHISPER_MODEL`, если их не меняли в интерфейсе.
4. Нажмите «Разметить спикеров» на вкладке «Расшифровка». После локальной обработки WAV появятся метки «Спикер 1», «Спикер 2» и обозначения неоднозначных реплик. Выделите реплику и нажмите «Переименовать спикера», чтобы подписать все его реплики. Исходная метка видна рядом с именем. Метки входят в экспорт расшифровки и передаются модели конспекта.
5. Нажмите «Сформировать конспект» и выберите профиль модели из вкладки «Настройки». В этом же диалоге можно изменить фокус, системный промпт и общий лимит времени генерации. По умолчанию лимит составляет 60 минут, а основной профиль берётся из настроек. Профиль «Внешний» перед генерацией показывает адрес провайдера, ID модели и состав передаваемых данных и требует подтверждения; аудио в облако не передаётся. Приложение обрабатывает длинные расшифровки по частям. Формат конспекта свободный. Если модель укажет ссылку на существующую реплику, приложение подставит её таймкод. Конспект можно редактировать, сохранять отдельными редакциями и выгружать в Markdown. Вкладка «Конспект» показывает Markdown в двух окнах: поле с разметкой и отформатированный просмотр. Над полем лежит лента форматирования с группами значков и подписями «Правка», «Стили», «Формат», «Абзац» и «Вставка»: она добавляет заголовки, списки, чек-листы, цитаты, блоки кода, таблицы и ссылки на таймкод текущего момента воспроизведения; наведение на значок показывает название и горячую клавишу. Режим просмотра переключается отдельными кнопками в нижней строке, справа от счётчика слов. В просмотре щёлкните ссылку вида «▶ 00:01:01», чтобы прослушать фрагмент. Для перехода по ссылке в поле поставьте курсор на нужную строку и нажмите «Прослушать по ссылке».

Индикатор «Входящий звук Chrome» показывает звук, который браузер встречи воспроизводит. При проверке с двух окон речь должна быть слышна в окне, открытом LectureNotes. Если захват получает только цифровую тишину, приложение показывает «нет входящего звука» и пропускает такой фрагмент при распознавании.

## Библиотека

Карточки, расшифровки и редакции конспектов хранятся в `library.sqlite`. Ссылки внутри базы защищены Windows DPAPI в контексте текущего пользователя. WAV остаются в каталоге `recordings`. При первом запуске SQLite-библиотеки приложение переносит карточки, расшифровки и редакции из файлового формата прототипа.

На вкладке «Запись» рядом с проигрывателем показан сохранённый черновик живой расшифровки. После окончания захвата щелчок по реплике запускает аудио с её таймкода. Кнопка «Изменить реплику» позволяет править текст черновика. На вкладке «Расшифровка» та же кнопка сохраняет исправление новой версией итоговой расшифровки с прежними таймкодами.

Поиск охватывает название, тему, текущую расшифровку и текущий конспект. Он учитывает русские словоформы, регистр и `ё/е`. Результат открывает карточку, конспект или выделяет реплику с таймкодом. В списке каждая лекция показана с датой и временем создания. Можно отфильтровать лекции по предмету, периоду, состоянию и наличию конспекта, а «Сбросить фильтры» очищает поиск и все фильтры сразу. Кнопка «Предметы» открывает вкладку управления предметами. На вкладке «Конспект» доступны ручное создание, история редакций и восстановление. Вкладка переключается между режимами «Правка», «Два окна» и «Просмотр», показывает число символов, слов и строк и отмечает несохранённые правки. Кнопки панели форматирования подписаны словами и переносятся на новую строку, если не помещаются. Работают сочетания Ctrl+B, Ctrl+I, Ctrl+E, Ctrl+K и Ctrl+S, а Enter продолжает список или цитату.

## Предметы

Вкладка «Предметы» собирает всё, что связано с предметами: поиск по названию и описанию с учётом `ё/е` и регистра, сортировку по названию или числу лекций, создание, переименование, описание и удаление. Карточка предмета показывает число лекций, расшифровок и конспектов, а справа — список лекций предмета с датой, состоянием обработки и наличием конспекта. Лекцию можно перенести в другой предмет по одной или все сразу; «Показать лекции в библиотеке» применяет фильтр по предмету во вкладке «Библиотека», «Открыть лекцию» переходит к её карточке. Предмет с лекциями удаляется только после переноса — приложение предлагает выбрать предмет для переноса и удаляет пустой. В форме лекции поле предмета стало списком с уже созданными названиями: можно выбрать предмет или вписать новый.

## Настройки

Вкладка «Настройки» хранит все настройки приложения в базе библиотеки, поэтому они действуют после перезапуска.

- **Модели и профили генерации.** Профиль содержит название, тип (локальный или внешний), базовый URL, ID модели, ключ API, бюджет контекста, лимит ответа и тайм-аут запроса. Профили создаются, изменяются, удаляются, помечаются основным и проверяются кнопкой «Проверить соединение» нейтральным запросом. Ключ шифруется Windows DPAPI и не хранится в открытом виде; локальный профиль работает только с `http://127.0.0.1:порт/v1`, внешний требует `https`. Лимит ответа передаётся модели как `max_tokens`, ключ — как `Authorization: Bearer`, тайм-аут ограничивает один запрос внутри общего лимита времени генерации.
- **Распознавание речи.** Путь к `whisper-cli.exe`, файл модели, язык распознавания (`ru`, `en`, `auto` или свой код) и режим «Только CPU». Кнопки выбора файлов и «Встроенные файлы» упрощают возврат к поставке.
- **Диаризация (sherpa-onnx).** Выберите совместимые ONNX-модели для сегментации речи и сравнения голосов. Можно заменить только одну из них. Нажмите «Сохранить модели» и запустите «Разметить спикеров» в расшифровке. Для возврата к комплекту нажмите «Встроенные модели» и сохраните выбор.
- **Конспект.** Системный промпт и общий лимит времени; «Промпт по умолчанию» возвращает исходный текст.
- **Библиотека.** Путь текущей библиотеки, счётчики предметов, лекций, расшифровок и конспектов, размер очереди очистки файлов и кнопка выбора папки.
- **О сборке.** Версии JDK и JavaFX, версия схемы SQLite, используемые файлы Whisper и путь к помощнику записи.

Кнопка «Удалить WAV» на вкладке «Запись» освобождает место, сохраняя карточку, расшифровки, метки спикеров и редакции конспекта. Удаление всей лекции также убирает её из библиотеки и поиска. Если Windows ещё держит открытым файл записи, приложение повторит очистку при следующем запуске.

По умолчанию данные хранятся в `%LOCALAPPDATA%\LectureNotes`. Чтобы открыть библиотеку в другом месте, нажмите «Папка библиотеки», укажите доступный для записи каталог и перезапустите приложение. Данные предыдущей библиотеки остаются в её каталоге. При запуске JAR путь также можно задать через `-Dlecturenotes.data=путь` перед `-jar`.

## Проверки

```powershell
.\tools\check-audio.ps1
.\tools\check-audio.ps1 -Chrome
.\tools\check-meeting.ps1
.\tools\check-processing.ps1
.\tools\check-note-ui.ps1
.\tools\check-tabs.ps1
```

Тест звука сравнивает сохранённый уровень двух контрольных тонов и проверяет восстановление WAV. С `-Chrome` источником звука служит локальная страница в отдельном браузере. Тест сначала проверяет, что Chrome начал воспроизведение, и выводит версию браузера, сборку Windows, PID и формат WAV. Если окно не открыло страницу или воспроизведение не запустилось, тест указывает путь к журналу Chrome в `target/audio-check`. Полный V-04 требует живой встречи, второго участника и проверки смены устройства на целевом ПК. Тест обработки проверяет PCM для whisper.cpp, перенос таймкодов и публикацию новой редакции с тестовым API. Флаг `-LiveModel` дополнительно проверяет генерацию через `iq3_s` на локальном порту 47831.

Параметр `-SpeechWav <путь>` дополнительно запускает обе версии Whisper и проверяет сохранение расшифровки. Используйте тестовую русскую речь в формате записи приложения, PCM 16 бит, 44,1 кГц, стерео.

`.\tools\check-live.ps1 -SpeechWav <путь>` проверяет расшифровку во время работы WASAPI, миграцию библиотеки и сохранение ссылки через DPAPI. По умолчанию скрипт берёт сборку с полной моделью из `target/standalone-app-full`. Параметр `-AppDirectory` принимает каталог с `lecture-notes.jar` из любой проверяемой сборки.

Проверка встречи использует локальные имитации экранов SaluteJazz. Она проверяет состояния комнаты, поведение при смене origin, разрешения камеры и микрофона, передачу PID в WASAPI и удаление временного профиля. Для проверки локаторов на реальных экранах нужна живая встреча.

Проверка вкладки «Конспект» открывает окно с редактором и просмотром. Она проверяет разбор Markdown (заголовки, обычные и вложенные списки, чек-листы, цитаты, таблицы, блоки кода, ссылки и разделители), переход по ссылке с таймкодом, группы ленты форматирования со значками вместо слов, отдельный переключатель режимов в нижней строке, продолжение списков по Enter и три режима вкладки. Для проверки нужен рабочий стол Windows.

`.\tools\check-tabs.ps1` открывает вкладки «Предметы» и «Настройки». Она проверяет счётчики лекций в карточке предмета, поиск по неточной словоформе, сортировку по популярности, список лекций предмета и доступность действий переноса, шесть карточек настроек, загрузку двух профилей с их лимитами, сохранённые пути Whisper, флаг CPU, промпт и лимит времени, счётчики библиотеки и отсутствие ошибок разбора `app.css`.

Вход, итоговая расшифровка, разметка спикеров и генерация конспекта запускаются вручную. Гостевое заполнение формы, корпоративный вход и очередь обработки описаны в [спецификации](src/main/resources/specs.md).
