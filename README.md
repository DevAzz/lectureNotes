# Конспекты лекций

Приложение для Windows 11 x64. Для сборки нужны JDK 25 и Maven. Пакет приложения включает Java runtime, JavaFX 21 и помощник WASAPI. Для подключения к встрече нужен установленный Google Chrome.

## Сборка и запуск

```powershell
.\tools\build.ps1 -AppImage
```

Скрипт выводит путь к `LectureNotes.exe` в `target/dist`. Запускайте его из папки пакета в обычном сеансе Windows. JAR для разработки доступен в `target/standalone-app`; рядом лежит `audio-capture.exe`.

```powershell
java --module-path target/standalone-app/lib --add-modules 'javafx.controls,javafx.media' '--enable-native-access=javafx.graphics,javafx.media,org.xerial.sqlitejdbc,ALL-UNNAMED' -jar target/standalone-app/lecture-notes.jar
```

Помощник собирается штатным компилятором .NET Framework из Windows. Maven может отдельно собрать Java-часть командой `mvn package`.

## Запись и конспект

1. Введите предмет, название и HTTPS-ссылку SaluteJazz. Тему и фокус конспекта можно указать отдельно. Чтобы создать карточку заранее, нажмите «Сохранить карточку». Для встречи нажмите «Подключиться» и войдите в отдельном окне Chrome. Дождитесь допуска, проверьте, что камера и микрофон выключены.
2. Подтвердите разрешение на запись и нажмите «Я на встрече · начать запись». Чтобы продолжить слушать после остановки захвата, используйте «Остановить запись».
3. Найдите WAV в библиотеке. «Распознать» запускает локальный `whisper-cli.exe` с указанным файлом модели. Опционально задайте пути через `LECTURENOTES_WHISPER` и `LECTURENOTES_WHISPER_MODEL`. Веса и исполняемый файл поставляются отдельно.
4. Выберите «Сформировать конспект» и укажите локальный OpenAI-compatible API на `127.0.0.1` и ID модели. Конспект можно редактировать, сохранять отдельными редакциями и выгружать в Markdown. Для перехода к записи поставьте курсор на строку со ссылкой и нажмите «Прослушать по ссылке».

## Библиотека

Карточки, расшифровки и редакции конспектов хранятся в `library.sqlite`. WAV остаются в каталоге `recordings`. При первом запуске SQLite-библиотеки приложение переносит карточки, расшифровки и редакции из файлового формата прототипа.

Поиск охватывает название, тему, текущую расшифровку и текущий конспект. Он учитывает русские словоформы, регистр и `ё/е`. Результат открывает карточку, конспект или выделяет реплику с таймкодом. В библиотеке можно отфильтровать лекции по предмету, периоду, состоянию и наличию конспекта. «Предметы» открывает управление предметами. Чтобы перенести лекцию, выберите другой предмет при изменении карточки. На вкладке «Конспект» доступны ручное создание, история редакций и восстановление.

Удалённая лекция сразу исчезает из библиотеки и поиска. Если Windows ещё держит открытым файл записи, приложение повторит очистку при следующем запуске.

Данные хранятся в `%LOCALAPPDATA%\LectureNotes`. Для отдельной библиотеки при запуске JAR можно задать `-Dlecturenotes.data=путь` перед `-jar`.

## Проверки

```powershell
.\tools\check-audio.ps1
.\tools\check-audio.ps1 -Chrome
.\tools\check-processing.ps1
```

Тест звука сравнивает сохранённый уровень двух контрольных тонов и проверяет восстановление WAV. С `-Chrome` источником звука служит локальная страница в отдельном браузере. Тест сначала проверяет, что Chrome начал воспроизведение, и выводит версию браузера, сборку Windows, PID и формат WAV. Если окно не открыло страницу или воспроизведение не запустилось, тест указывает путь к журналу Chrome в `target/audio-check`. Полный V-04 требует живой встречи, второго участника и проверки смены устройства на целевом ПК. Тест обработки проверяет PCM для whisper.cpp, перенос таймкодов и публикацию новой редакции с тестовым API. Флаг `-LiveModel` дополнительно проверяет генерацию через `iq3_s` на локальном порту 47831.

Вход, подтверждение допуска, распознавание и генерация запускаются вручную. Автоматизация входа через Playwright, диаризация, очередь обработки и профили моделей описаны в [спецификации](src/main/resources/specs.md).
