# Записи и конспекты

Приложение для Windows 11 x64. Для сборки нужны JDK 25 и Maven. Пакет включает Java runtime, JavaFX 21, помощник WASAPI, Whisper и sherpa-onnx. Для подключения к встрече нужен установленный Google Chrome.

## Сборка и запуск

```powershell
.\tools\build.ps1 -AppImage
```

Скрипт выводит путь к `RecordNotes.exe` в `target/dist`. Запускайте его из папки пакета в обычном сеансе Windows. JAR для разработки доступен в `target/standalone-runtime` рядом с `audio-capture.exe`.

```powershell
java --module-path target/standalone-runtime/lib --add-modules 'javafx.controls,javafx.media' '--enable-native-access=javafx.graphics,javafx.media,org.xerial.sqlitejdbc,ALL-UNNAMED' -jar target/standalone-runtime/lecture-notes.jar
```

Помощник собирается штатным компилятором .NET Framework из Windows. Maven может отдельно собрать Java-часть командой `mvn package`.

При сборке скрипты загружают движки whisper.cpp и sherpa-onnx с зависимостями и лицензиями. Для распознавания откройте «Настройки», скачайте Whisper Large v3 Turbo Q5_0 или Large v3 FP16 и нажмите «Сохранить движок». Для разметки спикеров скачайте обе модели, pyannote Segmentation 3.0 и 3D-Speaker ERes2Net, и нажмите «Сохранить модели».

Приложение проверяет SHA‑256 загрузок и сохраняет файлы в `%LOCALAPPDATA%\LectureNotes\models`. Все библиотеки пользователя могут использовать эти файлы.

## Запись и конспект

Для записи из любого браузера или приложения откройте вкладку «Запись», укажите коллекцию и название, оставьте ссылку пустой и нажмите «Записать звук компьютера». В запись попадёт воспроизводимый Windows звук, включая уведомления. Микрофон для этого режима не нужен. Кнопка «Остановить запись» сохранит запись в библиотеке.

Для записи по ссылке:

1. Укажите коллекцию, название и HTTP- или HTTPS-ссылку на страницу. Нажмите «Подключиться по ссылке». Приложение сохранит карточку и откроет страницу в отдельном окне Chrome. При необходимости войдите в сервис в этом окне. Камера и микрофон в нём выключены.
2. Когда будете готовы записывать звук этого окна, нажмите «Начать запись» на вкладке «Запись». Предварительная расшифровка появляется там же по мере распознавания восьмисекундных фрагментов. Она использует движок, сохранённый во вкладке «Настройки» до начала записи. Чтобы остановить захват и продолжить слушать, нажмите «Остановить запись».
3. Откройте запись в библиотеке и нажмите «Распознать» на вкладке «Расшифровка». Приложение запускает встроенный Whisper на NVIDIA GPU. Если CUDA не запускается, обработка продолжается на CPU. Движок, файл модели, язык распознавания и режим «Только CPU» задаются во вкладке «Настройки»; кнопка «Стандартные пути» подставляет стандартные пути. Пути также можно задать через `LECTURENOTES_WHISPER` и `LECTURENOTES_WHISPER_MODEL`, если их не меняли в интерфейсе.
4. Нажмите «Разметить спикеров» на вкладке «Расшифровка». После локальной обработки WAV появятся метки «Спикер 1», «Спикер 2» и обозначения неоднозначных реплик. Выделите реплику и нажмите «Переименовать спикера», чтобы подписать все его реплики. Исходная метка видна рядом с именем. Метки входят в экспорт расшифровки и передаются модели конспекта.
5. Нажмите «Разбить на абзацы» на вкладке «Текст». Реплики разбиваются на предложения и нумеруются, модель возвращает только номера строк, с которых начинается новый абзац, а формулировки расшифровки сохраняются дословно. Смена спикера всегда начинает абзац и подписывается «Спикер · ». В диалоге выбираются профиль модели, лимит времени и отдельный промпт разбивки, который сохраняется в библиотеке. Текст относится к конкретной версии расшифровки и исчезает, когда расшифровка меняется. «Экспорт Markdown» предлагает сохранить его как `recording.md`.
6. Нажмите «Сформировать конспект» и выберите профиль модели из вкладки «Настройки». В этом же диалоге можно изменить фокус, системный промпт и общий лимит времени генерации. По умолчанию лимит составляет 60 минут, а основной профиль берётся из настроек. Профиль «Внешний» перед генерацией показывает адрес провайдера, ID модели и состав передаваемых данных и требует подтверждения; аудио в облако не передаётся. Приложение обрабатывает длинные расшифровки по частям. Формат конспекта свободный. Модель указывает идентификатор реплики рядом с тезисом, который звучит в записи. Приложение проверяет идентификатор и подставляет время начала реплики. Конспект можно редактировать, сохранять отдельными редакциями и выгружать в Markdown. Вкладка «Конспект» показывает Markdown в двух окнах: поле с разметкой и отформатированный просмотр. В режиме «Два окна» обе панели прокручиваются вместе. В просмотре текст можно выделить мышью и скопировать через Ctrl+C. Над полем лежит лента форматирования с группами значков и подписями «Правка», «Стили», «Формат», «Абзац» и «Вставка»: она добавляет заголовки, списки, чек-листы, цитаты, блоки кода, таблицы и ссылки на таймкод текущего момента воспроизведения; наведение на значок показывает название и горячую клавишу. Режим просмотра переключается отдельными кнопками в нижней строке, справа от счётчика слов. В просмотре щёлкните ссылку вида «▶ 00:01:01», чтобы прослушать фрагмент. Для перехода по ссылке в поле поставьте курсор на нужную строку и нажмите «Прослушать по ссылке».

Индикатор «Уровень звука записи» показывает уровень захваченного сигнала. При подключении по ссылке звук должен быть слышен в окне, открытом приложением. Если захват получает только цифровую тишину, приложение показывает «нет входящего звука» и пропускает такой фрагмент при распознавании.

## Библиотека

Карточки, расшифровки и редакции конспектов хранятся в `library.sqlite`. Ссылки внутри базы защищены Windows DPAPI в контексте текущего пользователя. WAV остаются в каталоге `recordings`. При первом запуске SQLite-библиотеки приложение переносит карточки, расшифровки и редакции из файлового формата прототипа.

В карточке на вкладке «Запись» рядом с проигрывателем показан сохранённый черновик живой расшифровки. После окончания захвата щелчок по реплике запускает аудио с её таймкода. Кнопка «Изменить реплику» позволяет править текст черновика. На вкладке «Расшифровка» та же кнопка сохраняет исправление новой версией итоговой расшифровки с прежними таймкодами. Вкладка «Текст» показывает текущую расшифровку, разбитую на абзацы, и позволяет её экспортировать.

Поиск охватывает название, тему, текущую расшифровку и текущий конспект. Он учитывает русские словоформы, регистр и `ё/е`. Результат открывает карточку, конспект или выделяет реплику с таймкодом. Двойной щелчок или Enter на результате из конспекта прокручивает текст к совпадению и подсвечивает его на две секунды. В списке каждая запись показана с датой и временем создания. Можно отфильтровать записи по коллекции, периоду, состоянию и наличию конспекта. Кнопка «Сбросить фильтры» очищает поиск и все фильтры сразу. Кнопка «Коллекции» открывает одноимённую вкладку. На вкладке «Конспект» доступны ручное создание, история редакций и восстановление. Вкладка переключается между режимами «Правка», «Два окна» и «Просмотр», показывает число символов, слов и строк и отмечает несохранённые правки. Кнопки панели форматирования подписаны словами и переносятся на новую строку, если не помещаются. Работают сочетания Ctrl+B, Ctrl+I, Ctrl+E, Ctrl+K и Ctrl+S, а Enter продолжает список или цитату.

## Коллекции

На вкладке «Коллекции» можно создавать, переименовывать и удалять коллекции, искать их по названию и описанию с учётом `ё/е` и регистра, сортировать по названию или числу записей. В карточке коллекции видны счётчики и список записей с датой, состоянием обработки и наличием конспекта. Записи можно переносить по одной или все сразу. Кнопка «В библиотеку» применяет фильтр по коллекции, а «Открыть запись» переходит к её карточке. Перед удалением непустой коллекции приложение предлагает выбрать, куда перенести её записи. В форме записи можно выбрать существующую коллекцию или ввести новое название.

## Настройки

Настройки обработки хранятся в базе библиотеки и действуют после перезапуска.

- **Внешний вид.** По умолчанию включена тёмная тема. Светлую тему можно выбрать в выпадающем списке «Тема приложения». Оформление меняется сразу, а выбор сохраняется при перезапуске и смене папки библиотеки.

- **Модели и профили генерации.** Профиль содержит название, тип (локальный или внешний), базовый URL, ID модели, ключ API, бюджет контекста, лимит ответа и тайм-аут запроса. Профили создаются, изменяются, удаляются, помечаются основным и проверяются кнопкой «Проверить соединение» нейтральным запросом. Ключ шифруется Windows DPAPI и не хранится в открытом виде; локальный профиль работает только с `http://127.0.0.1:порт/v1`, внешний требует `https`. Лимит ответа передаётся модели как `max_tokens`, ключ — как `Authorization: Bearer`, тайм-аут ограничивает один запрос внутри общего лимита времени генерации.
- **Распознавание речи.** Путь к `whisper-cli.exe`, файл модели, язык распознавания (`ru`, `en`, `auto` или свой код) и режим «Только CPU». Кнопки выбора файлов и «Стандартные пути» упрощают выбор стандартной конфигурации.
- **Разделение по голосам.** Выберите совместимые ONNX-модели для сегментации речи и сравнения голосов. Можно заменить только одну из них. Нажмите «Сохранить модели» и запустите «Разметить спикеров» в расшифровке. Для возврата к стандартным путям нажмите «Стандартные модели» и сохраните выбор.
- **Конспект.** Системный промпт и общий лимит времени; «Промпт по умолчанию» возвращает исходный текст.
- **Библиотека.** Путь текущей библиотеки, счётчики коллекций, записей, расшифровок и конспектов, размер очереди очистки файлов и кнопка выбора папки.
- **О сборке.** Версии JDK и JavaFX, версия схемы SQLite, используемые файлы Whisper и путь к помощнику записи.

Кнопка «Удалить WAV» на вкладке «Запись» освобождает место, сохраняя карточку, расшифровки, метки спикеров и редакции конспекта. Удаление всей записи также убирает её из библиотеки и поиска. Если Windows ещё держит открытым файл записи, приложение повторит очистку при следующем запуске.

По умолчанию данные хранятся в `%LOCALAPPDATA%\LectureNotes`. Чтобы открыть библиотеку в другом месте, в настройках нажмите «Выбрать папку библиотеки», укажите доступный для записи каталог и перезапустите приложение. Данные предыдущей библиотеки остаются в её каталоге. При запуске JAR путь также можно задать через `-Dlecturenotes.data=путь` перед `-jar`.

## Проверки

```powershell
.\tools\check-audio.ps1
.\tools\check-audio.ps1 -Chrome
.\tools\check-meeting.ps1
.\tools\check-processing.ps1
.\tools\check-note-ui.ps1
.\tools\check-tabs.ps1
```

Тест звука сравнивает сохранённый уровень двух контрольных тонов и проверяет восстановление WAV. С `-Chrome` источником звука служит локальная страница в отдельном браузере. Тест сначала проверяет, что Chrome начал воспроизведение, и выводит версию браузера, сборку Windows, PID и формат WAV. Если окно не открыло страницу или воспроизведение не запустилось, тест указывает путь к журналу Chrome в `target/audio-check`. Полный V-04 требует живой встречи, второго участника и проверки смены устройства на целевом ПК. Тест обработки проверяет PCM для whisper.cpp, перенос таймкодов, публикацию новой редакции и разбиение текста на абзацы с сохранением слов расшифровки — всё это с тестовым API. Флаг `-LiveModel` дополнительно проверяет генерацию через `iq3_s` на локальном порту 47831.

Параметр `-SpeechWav <путь>` дополнительно запускает обе версии Whisper и проверяет сохранение расшифровки. Используйте тестовую русскую речь в формате записи приложения, PCM 16 бит, 44,1 кГц, стерео.

`.\tools\check-live.ps1 -SpeechWav <путь>` проверяет расшифровку во время работы WASAPI, миграцию библиотеки и сохранение ссылки через DPAPI. По умолчанию скрипт берёт сборку из `target/standalone-runtime`. Параметр `-AppDirectory` принимает каталог с `lecture-notes.jar` из любой проверяемой сборки.

Проверка встречи открывает локальную веб-страницу, проверяет захват звука Chrome, разрешения камеры и микрофона и удаление временного профиля.

Проверка вкладки «Конспект» открывает окно с редактором и просмотром. Она проверяет разбор Markdown (заголовки, обычные и вложенные списки, чек-листы, цитаты, таблицы, блоки кода, ссылки и разделители), переход по ссылке с таймкодом, группы ленты форматирования со значками вместо слов, отдельный переключатель режимов в нижней строке, продолжение списков по Enter и три режима вкладки. Для проверки нужен рабочий стол Windows.

`.\tools\check-tabs.ps1` открывает вкладки «Коллекции» и «Настройки». Скрипт проверяет счётчики и список записей коллекции, поиск по неточной словоформе, сортировку по числу записей и доступность переноса. Он также проверяет переключение и сохранение темы, загрузку профилей с их лимитами, пути Whisper, флаг CPU, промпты, лимит времени, счётчики библиотеки и отсутствие ошибок разбора CSS.

Вход, итоговая расшифровка, разметка спикеров и генерация конспекта запускаются вручную. Гостевое заполнение формы, корпоративный вход и очередь обработки описаны в [спецификации](src/main/resources/specs.md).
