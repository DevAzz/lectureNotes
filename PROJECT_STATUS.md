# LectureNotes — состояние проекта

Windows-прототип приложения связывает запись WAV, библиотеку, локальное распознавание и генерацию конспекта по сохранённому тексту. Библиотека работает на JavaFX и SQLite. Экраны разложены по вкладкам: «Лекция», «Библиотека», «Предметы» и «Настройки».

## Что реализовано

- **Подключение к лекции.** Playwright 1.65.1 открывает HTTP- или HTTPS-ссылку в установленном Chrome с временным профилем и заблокированным доступом к камере и микрофону. Приложение проверяет PID, каталог профиля и время запуска Chrome. Ссылка передаётся по каналу Playwright.
- **Начало и завершение.** Нажатие «Начать запись» запускает захват звука открытого окна. При неожиданном закрытии окна доступное аудио сохраняется как частичная запись.
- **Запись звука.** Помощник на C# использует WASAPI process loopback для дерева процессов отдельного Chrome. Браузер продолжает выводить звук на устройство Windows. Кнопка «Остановить запись» сохраняет записанную часть и оставляет окно встречи открытым. Звук сохраняется в WAV-чанках до 60 секунд, а после сбоя помощник может восстановить целые PCM-кадры из незавершённого файла.
- **Интерфейс и проигрыватель.** Экраны встречи, библиотеки, расшифровки и конспекта работают на JavaFX 21. Проигрыватель на JavaFX MediaPlayer поддерживает паузу, громкость, перемотку и переходы по таймкодам на общей шкале. Библиотека показывает интервалы пропусков между WAV-чанками. На вкладке «Лекция» во время записи пополняется черновик расшифровки по восьмисекундным фрагментам. Диалоги и сообщения ограничены шириной экрана, поэтому кнопки подтверждения видны при любой длине названия, пути или промпта.
- **Библиотека.** SQLite хранит предметы, карточки, состояния записи, расшифровки и редакции конспектов. Можно создать карточку до встречи, сохранить HTTPS-приглашение, изменить карточку, перенести её в другой предмет и удалить вместе со связанными материалами. В списке результатов у каждой лекции показаны дата и время создания. Кнопка «Сбросить фильтры» очищает поиск и все фильтры и остаётся неактивной, когда сбрасывать нечего. Приглашение защищено Windows DPAPI и подставляется при открытии карточки для встречи. При первом запуске приложение импортирует данные файлового прототипа. WAV читаются из прежних каталогов.
- **Поиск.** SQLite FTS5 индексирует название, тему, реплики текущей расшифровки и текущий конспект. Lucene RussianAnalyzer учитывает русские словоформы. Есть нормализация `ё/е`, поиск технических кодов, комбинированные фильтры и сортировки. Результат из расшифровки показывает таймкод и выделяет соответствующую реплику.
- **Расшифровка.** В Windows-пакете есть CUDA- и CPU-сборки whisper.cpp v1.8.4. Модели Whisper Large v3 Turbo Q5_0 и Large v3 FP16 скачиваются в настройках. Встроенный Whisper декодирует исходные WAV. Для внешнего движка приложение преобразует запись в PCM 16 кГц, моно, 16 бит. Результат из одних звуковых пометок помечается как ошибка распознавания. Таймкоды SRT переводятся в общую шкалу записи. Из списка реплик можно перейти к прослушиванию, а расшифровку можно выгрузить в Markdown.
- **Спикеры.** Вкладка «Расшифровка» запускает локальную диаризацию WAV на CPU через sherpa-onnx. Метки сопоставляются с репликами по таймкодам и сохраняются новой версией. У неоднозначных реплик есть отдельные обозначения. Пользователь может назначить имя всем репликам спикера с сохранением исходной метки.
- **Конспект.** Сохранённую расшифровку можно передать локальному OpenAI-compatible API после перезапуска. Формат конспекта свободный, системный промпт и общий лимит времени редактируются в диалоге генерации и сохраняются в SQLite. Лимит по умолчанию составляет 60 минут. Длинные записи обрабатываются по частям. Ссылки на существующие реплики превращаются в таймкоды. Конспект можно создать вручную, отредактировать и экспортировать в Markdown. Каждое сохранение создаёт отдельную редакцию. Предыдущую редакцию можно восстановить. Вкладка «Конспект» построена вокруг Markdown-редактора: лента форматирования, поле разметки и живой просмотр на элементах JavaFX без внешних зависимостей. Лента собрана из групп с подписями («Правка», «Стили», «Формат», «Абзац», «Вставка»), внутри групп — значки без слов; значки нарисованы векторными фигурами и не зависят от иконочных шрифтов, у каждого есть подсказка с названием и горячей клавишей. Группы переносятся на следующую строку, если не помещаются по ширине. Режимы просмотра (правка, два окна, просмотр) вынесены в отдельный переключатель в нижней строке рядом со счётчиком текста, а в режиме просмотра инструменты правки отключаются. Просмотр различает заголовки, обычные и вложенные списки, чек-листы, цитаты, таблицы, блоки кода и ссылки. Ссылка на таймкод по щелчку запускает воспроизведение, обычная ссылка открывается в системном браузере. Окно приложения использует общий стилевой файл `app.css`.
- **Текст для чтения.** Вкладка «Текст для чтения» собирает из расшифровки сплошной текст абзацами. Модель возвращает только номера строк, с которых начинается новый абзац: реплики делятся на предложения по русским правилам и нумеруются, а формулировки склеиваются дословно. Смена спикера всегда начинает абзац и добавляет его подпись. Текст хранится в колонке `reading_text` текущей версии расшифровки (схема v7) и очищается при её изменении; промпт разбивки лежит в `app_setting`, есть экспорт Markdown.
- **Правка реплик.** Вкладка «Запись» показывает сохранённый черновик живой расшифровки. Щелчок по реплике после окончания захвата начинает воспроизведение с её таймкода. Текст черновика можно исправить. Правка итоговой расшифровки создаёт новую версию с прежними интервалами и обновляет полнотекстовый индекс.
- **Хранение.** «Удалить WAV» удаляет оригиналы записи с сохранением документов лекции. Кнопка «Папка библиотеки» позволяет выбрать каталог данных для следующего запуска приложения.
- **Предметы.** Отдельная вкладка хранит всё, что связано с предметами: поиск по названию и описанию с нормализацией `ё/е` и регистра, сортировку по названию или числу лекций, создание, переименование, описание и удаление. Карточка предмета показывает число лекций, расшифровок и конспектов, рядом выводится список лекций предмета с датой, состоянием и наличием конспекта. Лекцию можно перенести по одной или все сразу, а предмет с лекциями удаляется только после переноса — приложение предлагает предмет для переноса и удаляет пустой. Кнопки «Показать лекции в библиотеке» и «Открыть лекцию» связывают вкладку с библиотекой. В форме лекции поле предмета — редактируемый список уже созданных названий.
- **Настройки.** Вкладка настроек хранит всё в таблице `app_setting` и `model_profile` схемы v7. Профили генерации (название, локальный или внешний тип, базовый URL, ID модели, ключ API, бюджет контекста, лимит ответа, тайм-аут) создаются, изменяются, удаляются, помечаются основным и проверяются нейтральным запросом. Ключ шифруется DPAPI. Локальный профиль принимается только для `http://127.0.0.1:порт/v1`, внешний — только по HTTPS; лимит ответа уходит в `max_tokens`, ключ — в `Authorization: Bearer`, тайм-аут ограничивает один запрос внутри общего лимита времени. Для внешнего профиля приложение перед генерацией показывает origin, модель и состав передаваемых данных. Здесь же настраиваются движок Whisper (путь, модель, язык, «Только CPU», возврат к встроенным файлам), системный промпт и лимит времени конспекта, отображаются путь библиотеки, счётчики и сведения о сборке.
- **Сборка.** Java-часть собирается Maven на JDK 25. Скрипт `tools/build.ps1 -AppImage` собирает помощник WASAPI, JAR и Windows-пакет с Java runtime и JavaFX. Порядок запуска описан в [README](README.md).

- Локальный Windows-пакет с новыми вкладками находится в `target/dist/20261127-151108-441/LectureNotes/LectureNotes.exe` (сборка `tools/build.ps1 -AppImage -FullWhisper`, 4,0 ГБ). В него включены вкладки «Предметы» и «Настройки», профили моделей со схемой SQLite v6, лента форматирования вкладки «Конспект», редактор и просмотр Markdown, общий стилевой файл, движок разметки спикеров и Whisper Large v3 FP16 с CUDA- и CPU-сборками. `LectureNotes.exe --check` завершился успешно: JDK 25, помощник записи, модель `ggml-large-v3.bin`, SQLite FTS5 с RussianAnalyzer, JavaFX 21.0.13 и драйвер Playwright. В этой версии пакет без флага `-FullWhisper` включал `ggml-large-v3-turbo-q5_0.bin`. - Сборка ассетов требует системного `tar.exe` из `System32`: в оболочке Git Bash первым в PATH стоит GNU tar, и распаковка sherpa-onnx падает с `Cannot connect to C:`. Перед запуском нужно поставить `C:\Windows\System32` в начало PATH.
- Для живой расшифровки Whisper запускается на каждом фрагменте. Следующая проверка в браузере — задержка текста на более длинной встрече и переход между WAV-чанками.
