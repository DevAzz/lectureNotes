# LectureNotes — состояние проекта

Собран первый Windows-прототип приложения для записи лекций и подготовки конспектов. Он связывает запись WAV, библиотеку, вызов локального распознавания и генерацию конспекта по сохранённому тексту. Код прототипа находится в коммите `6da5f22`.

## Что реализовано

- **Подключение к лекции.** Приложение открывает HTTPS-приглашение SaluteJazz в отдельном окне Chrome с временным профилем. Вход и подтверждение допуска выполняет пользователь. Запись запускается после подтверждения допуска и разрешения. Приглашение передаётся браузеру через одноразовый локальный адрес.
- **Проверка запуска Chrome.** Приложение ждёт, пока Chrome обратится к одноразовому адресу. Если браузер завершился или запрос не пришёл за 15 секунд, приложение сообщает причину и очищает временный профиль. При неожиданном закрытии окна после начала захвата доступное аудио сохраняется как частичная запись.
- **Запись звука.** Помощник на C# использует WASAPI process loopback для дерева процессов отдельного Chrome. Браузер продолжает выводить звук на устройство Windows. Кнопка «Остановить запись» сохраняет записанную часть и оставляет окно встречи открытым. Звук сохраняется в WAV-чанках до 60 секунд, а после сбоя помощник может восстановить целые PCM-кадры из незавершённого файла.
- **Библиотека и проигрыватель.** Приложение хранит карточки и файлы локально, ищет по названию и предмету, показывает пропуски между чанками и поддерживает перемотку по общей шкале записи.
- **Расшифровка.** Приложение преобразует запись в PCM 16 кГц, моно, 16 бит и запускает `whisper-cli`. Таймкоды SRT переводятся в общую шкалу записи. Из списка реплик можно перейти к прослушиванию, а расшифровку можно выгрузить в Markdown. Для запуска распознавания нужны `whisper-cli.exe` и файл модели.
- **Конспект.** Сохранённую расшифровку можно передать локальному OpenAI-compatible API отдельной командой, в том числе после перезапуска. Приложение проверяет ссылки модели на реплики и подставляет время из расшифровки. Конспект редактируется и экспортируется в Markdown. Каждое сохранение создаёт отдельную редакцию.
- **Сборка.** Java-часть собирается на установленном JDK 25. Скрипт `tools/build.ps1 -AppImage` собирает помощник WASAPI, JAR и Windows-пакет с собственным Java runtime. Порядок запуска описан в [README](README.md).

## Что подтверждено проверками

| Проверка | Результат |
| --- | --- |
| Maven и Windows-пакет | Java-часть собрана Maven. Запуск упакованного `LectureNotes.exe --check` завершился успешно. |
| Изоляция звука и восстановление WAV | На Windows 11, сборка 26200, в захвате был тон 440 Гц целевого процесса. Уровень контрольного тона 997 Гц из другого процесса оказался ниже порога теста. Помощник отбросил неполный кадр и восстановил WAV, который совпал с исходным по хешу. |
| Захват звука Chrome с локальной страницы | 26.11.2026, Windows 11 26200.9974, Chrome 158.0.8127.38, PID 30008. Формат WAV: PCM 16 бит, 44,1 кГц, стерео. Амплитуда 440 Гц составила 6590,38, сторонних 997 Гц — 11,05 при пороге 131,81. Восстановленный WAV совпал с исходным по хешу. |
| Запуск браузера и частичная запись | Локальная проверка подтвердила переход через одноразовый адрес, удаление временного профиля и сохранение аудио со статусом `PARTIAL` при имитации неожиданного завершения встречи. |
| Обработка контрольного материала | Проверены преобразование WAV, перенос таймкодов из SRT, генерация через тестовый API и через локальную модель `iq3_s`. Конспект содержал ссылку на реплику, а ручная редакция сохранилась отдельным файлом. |

Для ревью остановки захвата и восстановления WAV использовали локальный агент `pi`.

## Что остаётся до приёмки MVP

- Пройти V-04 на живой встрече. Проверить речь второго участника при живом прослушивании и в записи, сторонний звук, смену устройства вывода, сворачивание браузера и режим «Только аудио». Провести испытания гостевого и корпоративного входа.
- Обработать реальную русскоязычную лекцию со вторым участником. Проверить распознавание терминов, разметку говорящих и соответствие каждой проверяемой ссылки тезису конспекта. Текущая проверка генерации использовала контрольную расшифровку.
- Реализовать предусмотренные спецификацией JavaFX, автоматизацию через Playwright, библиотеку на SQLite с полнотекстовым поиском, диаризацию, возобновляемую очередь и профили внешних моделей. Сейчас интерфейс работает на Swing, библиотека хранится в файлах, а распознавание и генерация запускаются вручную.

Требования, критерии приёмки и порядок работ описаны в [спецификации](src/main/resources/specs.md).
