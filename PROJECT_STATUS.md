# LectureNotes — состояние проекта

Windows-прототип приложения связывает запись WAV, библиотеку, локальное распознавание и генерацию конспекта по сохранённому тексту. Библиотека работает на JavaFX и SQLite. Начата автоматизация подключения к SaluteJazz.

## Что реализовано

- **Подключение к лекции.** Playwright 1.65.1 открывает HTTPS-приглашение SaluteJazz в установленном Chrome с временным профилем и заблокированным доступом к камере и микрофону. Приложение проверяет PID, каталог профиля и время запуска Chrome. Ссылка передаётся по каналу Playwright.
- **Допуск и завершение.** Наблюдение за экраном различает предпросмотр, ожидание, активную комнату, отказ, переподключение и завершение. Кнопка «Подключиться и записать» подтверждает запуск записи, а захват начинается после распознанного допуска. На незнакомом экране с тем же HTTPS-origin пользователь может подтвердить допуск вручную. При неожиданном закрытии окна доступное аудио сохраняется как частичная запись.
- **Запись звука.** Помощник на C# использует WASAPI process loopback для дерева процессов отдельного Chrome. Браузер продолжает выводить звук на устройство Windows. Кнопка «Остановить запись» сохраняет записанную часть и оставляет окно встречи открытым. Звук сохраняется в WAV-чанках до 60 секунд, а после сбоя помощник может восстановить целые PCM-кадры из незавершённого файла.
- **Интерфейс и проигрыватель.** Экраны встречи, библиотеки, расшифровки и конспекта работают на JavaFX 21. Проигрыватель на JavaFX MediaPlayer поддерживает паузу, громкость, перемотку и переходы по таймкодам на общей шкале. Библиотека показывает интервалы пропусков между WAV-чанками. На вкладке «Лекция» во время записи пополняется черновик расшифровки по восьмисекундным фрагментам. Диалоги и сообщения ограничены шириной экрана, поэтому кнопки подтверждения видны при любой длине названия, пути или промпта.
- **Библиотека.** SQLite хранит предметы, карточки, состояния записи, расшифровки и редакции конспектов. Можно создать карточку до встречи, сохранить HTTPS-приглашение, изменить карточку, перенести её в другой предмет и удалить вместе со связанными материалами. В списке результатов у каждой лекции показаны дата и время создания. Кнопка «Сбросить фильтры» очищает поиск и все фильтры и остаётся неактивной, когда сбрасывать нечего. Приглашение защищено Windows DPAPI и подставляется при открытии карточки для встречи. При первом запуске приложение импортирует данные файлового прототипа. WAV читаются из прежних каталогов.
- **Поиск.** SQLite FTS5 индексирует название, тему, реплики текущей расшифровки и текущий конспект. Lucene RussianAnalyzer учитывает русские словоформы. Есть нормализация `ё/е`, поиск технических кодов, комбинированные фильтры и сортировки. Результат из расшифровки показывает таймкод и выделяет соответствующую реплику.
- **Расшифровка.** В Windows-пакете есть CUDA- и CPU-сборки whisper.cpp v1.8.4 и мультиязычная модель `ggml-large-v3-turbo-q5_0.bin`. Встроенный Whisper декодирует исходные WAV. Для внешнего движка приложение преобразует запись в PCM 16 кГц, моно, 16 бит. Результат из одних звуковых пометок помечается как ошибка распознавания. Таймкоды SRT переводятся в общую шкалу записи. Из списка реплик можно перейти к прослушиванию, а расшифровку можно выгрузить в Markdown.
- **Спикеры.** Вкладка «Расшифровка» запускает локальную диаризацию WAV на CPU через sherpa-onnx. Метки сопоставляются с репликами по таймкодам и сохраняются новой версией. У неоднозначных реплик есть отдельные обозначения. Пользователь может назначить имя всем репликам спикера с сохранением исходной метки.
- **Конспект.** Сохранённую расшифровку можно передать локальному OpenAI-compatible API после перезапуска. Формат конспекта свободный, системный промпт и общий лимит времени редактируются в диалоге генерации и сохраняются в SQLite. Лимит по умолчанию составляет 60 минут. Длинные записи обрабатываются по частям. Ссылки на существующие реплики превращаются в таймкоды. Конспект можно создать вручную, отредактировать и экспортировать в Markdown. Каждое сохранение создаёт отдельную редакцию. Предыдущую редакцию можно восстановить. Вкладка «Конспект» построена вокруг Markdown-редактора: панель форматирования, поле разметки и живой просмотр на элементах JavaFX без внешних зависимостей. Кнопки панели подписаны словами, держатся вместе группами и переносятся на следующую строку, если не помещаются по ширине. Просмотр различает заголовки, обычные и вложенные списки, чек-листы, цитаты, таблицы, блоки кода и ссылки. Ссылка на таймкод по щелчку запускает воспроизведение, обычная ссылка открывается в системном браузере. Окно приложения использует общий стилевой файл `app.css`.
- **Правка реплик.** Вкладка «Запись» показывает сохранённый черновик живой расшифровки. Щелчок по реплике после окончания захвата начинает воспроизведение с её таймкода. Текст черновика можно исправить. Правка итоговой расшифровки создаёт новую версию с прежними интервалами и обновляет полнотекстовый индекс.
- **Хранение.** «Удалить WAV» удаляет оригиналы записи с сохранением документов лекции. Кнопка «Папка библиотеки» позволяет выбрать каталог данных для следующего запуска приложения.
- **Сборка.** Java-часть собирается Maven на JDK 25. Скрипт `tools/build.ps1 -AppImage` собирает помощник WASAPI, JAR и Windows-пакет с Java runtime и JavaFX. Порядок запуска описан в [README](README.md).
