# LectureNotes — состояние проекта

Windows-прототип приложения связывает запись WAV, библиотеку, локальное распознавание и генерацию конспекта по сохранённому тексту. Первый прототип находится в коммите `6da5f22`. Текущий этап переносит приложение на JavaFX и SQLite.

## Что реализовано

- **Подключение к лекции.** Приложение открывает HTTPS-приглашение SaluteJazz в отдельном окне Chrome с временным профилем. Вход и подтверждение допуска выполняет пользователь. Запись запускается после подтверждения допуска и разрешения. Приглашение передаётся браузеру через одноразовый локальный адрес.
- **Проверка запуска Chrome.** Приложение ждёт, пока Chrome обратится к одноразовому адресу. Если браузер завершился или запрос не пришёл за 15 секунд, приложение сообщает причину и очищает временный профиль. При неожиданном закрытии окна после начала захвата доступное аудио сохраняется как частичная запись.
- **Запись звука.** Помощник на C# использует WASAPI process loopback для дерева процессов отдельного Chrome. Браузер продолжает выводить звук на устройство Windows. Кнопка «Остановить запись» сохраняет записанную часть и оставляет окно встречи открытым. Звук сохраняется в WAV-чанках до 60 секунд, а после сбоя помощник может восстановить целые PCM-кадры из незавершённого файла.
- **Интерфейс и проигрыватель.** Экраны встречи, библиотеки, расшифровки и конспекта работают на JavaFX 21. Проигрыватель на JavaFX MediaPlayer поддерживает паузу, громкость, перемотку и переходы по таймкодам на общей шкале. Библиотека показывает интервалы пропусков между WAV-чанками.
- **Библиотека.** SQLite хранит предметы, карточки, состояния записи, расшифровки и редакции конспектов. Можно создать карточку до встречи, изменить её, перенести в другой предмет и удалить вместе со связанными материалами. При первом запуске приложение импортирует данные файлового прототипа. WAV читаются из прежних каталогов.
- **Поиск.** SQLite FTS5 индексирует название, тему, реплики текущей расшифровки и текущий конспект. Lucene RussianAnalyzer учитывает русские словоформы. Есть нормализация `ё/е`, поиск технических кодов, комбинированные фильтры и сортировки. Результат из расшифровки показывает таймкод и выделяет соответствующую реплику.
- **Расшифровка.** Приложение преобразует запись в PCM 16 кГц, моно, 16 бит и запускает `whisper-cli`. Таймкоды SRT переводятся в общую шкалу записи. Из списка реплик можно перейти к прослушиванию, а расшифровку можно выгрузить в Markdown. Для запуска распознавания нужны `whisper-cli.exe` и файл модели.
- **Конспект.** Сохранённую расшифровку можно передать локальному OpenAI-compatible API после перезапуска. Приложение проверяет ссылки модели на реплики и подставляет время из расшифровки. Конспект можно создать вручную, отредактировать и экспортировать в Markdown. Каждое сохранение создаёт отдельную редакцию. Предыдущую редакцию можно восстановить.
- **Сборка.** Java-часть собирается Maven на JDK 25. Скрипт `tools/build.ps1 -AppImage` собирает помощник WASAPI, JAR и Windows-пакет с Java runtime и JavaFX. Порядок запуска описан в [README](README.md).

## Что подтверждено проверками

| Проверка | Результат |
| --- | --- |
| Maven и Windows-пакет | Java-часть собрана Maven. Запуск упакованного `LectureNotes.exe --check` завершился успешно. |
| JavaFX и SQLite | На локальных данных проверены открытие окна, воспроизведение WAV через JavaFX, импорт карточки и редакций, поиск «дифференциального уравнения» и «расчет», фильтры, перенос карточки и исчезновение удалённой лекции из индекса. Занятый Windows файл записи очистился при следующем запуске. |
| Изоляция звука и восстановление WAV | На Windows 11, сборка 26200, в захвате был тон 440 Гц целевого процесса. Уровень контрольного тона 997 Гц из другого процесса оказался ниже порога теста. Помощник отбросил неполный кадр и восстановил WAV, который совпал с исходным по хешу. |
| Захват звука Chrome с локальной страницы | 26.11.2026, Windows 11 26200.9974, Chrome 158.0.8127.38, PID 30008. Формат WAV: PCM 16 бит, 44,1 кГц, стерео. Амплитуда 440 Гц составила 6590,38, сторонних 997 Гц — 11,05 при пороге 131,81. Восстановленный WAV совпал с исходным по хешу. |
| Запуск браузера и частичная запись | Локальная проверка подтвердила переход через одноразовый адрес, удаление временного профиля и сохранение аудио со статусом `PARTIAL` при имитации неожиданного завершения встречи. |
| Обработка контрольного материала | После переноса на SQLite повторно проверены преобразование WAV, перенос таймкодов из SRT и генерация через локальный тестовый API. Генерация сохранила ссылку на реплику и предыдущую редакцию. В файловом прототипе также проверена локальная модель `iq3_s`. |

Для ревью остановки захвата и восстановления WAV использовали локальный агент `pi`.
